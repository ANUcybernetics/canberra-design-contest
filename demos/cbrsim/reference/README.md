# Reference images

The Gimson images are kept in git.
They are small, and the app loads one of them as `prototype/assets/gimson_plan.jpg`.

The NLA scans of the Australian, French and Gummer entries are not kept in git.
Each is about 3 MB.
To work with one, download it from the URL in that folder's `SOURCE.md` and save it beside the `SOURCE.md` under the file name listed there.
`.gitignore` keeps the downloaded scans out of commits.
